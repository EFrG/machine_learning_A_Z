# Machine Learning Project Setup

## Description
This project is a machine learning environment setup for macOS (M3 MacBook).

## Requirements
- Python 3.x
- macOS Terminal

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd <repository-folder>

2. If the requirements are not installed, run the setup.sh file:
   ```bash 
   bash setup.sh

3. Activate the virtual environment:
   ```bash
   source venv/bin/activate

4. (When done)
   ```bash
   deactivate
